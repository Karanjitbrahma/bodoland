## 🎨 Design System Specifications

### Typography
- **Headlines & Display:** Playfair Display
- **Body & Subtitles:** Plus Jakarta Sans / Inter
- **Metadata & Labels:** Plus Jakarta Sans (tracked uppercase)

### Editorial Color Palette
- **Primary:** `#002413` / `#0B3B24` (Deep Forest Green)
- **Secondary Accent:** `#7F5700` / `#D99B26` (Golden Ochre)
- **Background & Canvas:** `#F7FAF6` / `#FAF8F5` (Warm Ivory / Editorial Newsprint)
- **Surface Elevation:** `#FFFFFF` (Pure Crisp White)
- **Neutral Charcoal:** `#181C1A` / `#1A1E1C` (High-legibility typography)
